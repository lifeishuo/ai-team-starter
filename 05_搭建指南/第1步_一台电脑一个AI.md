# 第 1 步：一台电脑，一个 AI

**目标**：交出去一件真事，AI 自己拆步骤做完，另一个全新对话来检查。
**要什么**：一台电脑；一个 AI（有“能动手”的最好，只有聊天的也行）。
**花多少**：AI 工具的会员费，以各家官网为准；这一步不需要别的花销。
**多久**：第一次 30 分钟到半天，主要花在填宪法和想清楚第一件活。

先看你是哪种：

- 有一个**能动手的 AI**（能在你电脑上读写文件、跑命令）→ 看下面「能动手版」。
- 只有**聊天 AI**（网页或手机里对话）→ 跳到「聊天版」。

具体哪些工具实测过、哪些没测，见 [工具清单](工具清单.md)。

---

## 能动手版

### 1. 建一个工作文件夹

```
我的AI团队/
├── 宪法.md          ← 从 02_宪法模板/ 复制，填空
├── <开工说明>       ← 从 04_模板/开工说明.md 复制，文件名按工具清单改
├── 任务单模板.md    ← 从 04_模板/任务单.md 复制、改名
├── 记忆卡.md        ← 从 04_模板/ 复制（第 2 步用）
├── <技能文件夹>/    ← 把 03_技能/ 里 4 个文件夹复制进去；用 Claude Code 时是 .claude/skills/，其他见工具清单
├── 任务/            ← 放任务单
├── 材料/            ← 放这次要用的原始文件
├── 记忆/            ← 先空着，第 2 步用
└── 交付/            ← AI 做完的东西放这里
```

### 2. 填宪法（10 分钟）

只填三处就能开始：目标（第一节）、哪些事必须先问你（第四节）、你说话的方式（第五节）。三个杠杆和一个入口，第 2 步再细化。

### 3. 写第一张任务单（10 分钟）

复制 `任务单模板.md` 到 `任务/` 并改个名字，写一件**今天真想交出去、半小时内能做完、做坏了也不心疼**的小事。比如整理一份资料、写一份清单、把几份记录合成一页。把要用的原始文件放进 `材料/`。

最关键的是“做完的标准”：写成查的人能一条条打勾的样子。

### 4. 交出去，然后离开

在这个文件夹里打开你的 AI 工具，说：

```
用 split-and-do 技能，按 任务/<你的任务单>.md 干活。
```

**第一次先在旁边看一两分钟**：工具第一次要写文件时会停下来问你，选“这次都允许”（只对这个文件夹）。看它开始干了，再去做别的——否则它会一直停在那个问题上等你。AI 会拆步骤，在 `交付/` 里留下产出和 `graph.md`、`checks.md`、`progress.md`。

### 5. 开一个新对话来查

**关掉刚才的对话**（或新开一个），说：

```
用 maker-checker 技能，检查 任务/<你的任务单>.md 这件活，产出在 交付/<那件活>/。只出问题单，不改文件。
```

它会按“做完的标准”逐条给出通过 / 不通过和证据。不过的，把问题单交回给干活的对话（或新开一个），让它“只改问题单里的这几条”。

### 6. 你只做一件事：判断结果好不好

不好的话，先想是不是任务单没写清楚。把补充写回任务单，下次就不会错。

## 聊天版

聊天 AI 不能自己读写你电脑上的文件，所以由你来“搬运”：

1. 新开一个对话，把下面三样**依次粘贴**进去：
   - `宪法.md`（填好的）
   - `03_技能/split-and-do/SKILL.md` 的全文
   - 你的任务单（材料直接贴在任务单后面）
2. 最后说：“按上面的技能完成这张任务单。你不能读写文件、不能运行程序，所以所有产出直接写在回复里；技能里要写脚本的步骤，改成你逐条手工核对并把核对过程写出来。先给我节点表，再逐个节点做完，最后按‘做完的标准’逐条自查，给出通过/不通过和证据。”
3. 把它的结果复制下来。
4. **新开一个对话**，粘贴：`03_技能/maker-checker/SKILL.md` 全文 + 任务单（连同材料）+ 刚才的结果，说：“按这个技能检查，只出问题单。这是聊天版，产出写在回复里就算交付，不要求建文件。”
5. 把问题单贴回第一个对话，让它只改这几条。

聊天版的上限：AI 记不住上次聊了什么，每次都要重新贴宪法；材料多了贴不下。做顺手了就该换一个能动手的 AI。

## 常见的坑

- **第一件活挑太大**：第一次就让它“搭一个完整系统”，十有八九返工。先挑小的。
- **“做完的标准”写成感觉**：“写得好一点”没法查。写成能打勾的。
- **在旁边盯着**：交出去就离开。它中途问你的，大多数在宪法和任务单里本该写清。回来把答案补进去。
- **让干活的那个对话自己查自己**：一定要新开对话。
- **把密码、密钥写进任何文件**：AI 读得到的地方都不要放。
