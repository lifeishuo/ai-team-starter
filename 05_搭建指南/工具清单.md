# 工具清单：装哪个、放哪、测没测过

> 这一页是全包里唯一写具体工具名的地方。工具更新很快，下面的位置和用法以各工具官方文档为准。
> **“实测”** = 这个包发布前，在一台没装过任何东西的空文件夹里，按第 1、2 步从头照做跑通过。**“未测”** = 没这样跑过，只是写了做法，可能要你自己摸索。

## 一、实测过的组合

### 能动手的 AI：Claude Code（命令行版，macOS）

| 放什么 | 放哪 |
|---|---|
| 技能（`03_技能/` 里 4 个文件夹） | 工作文件夹里的 `.claude/skills/`（只对这个文件夹生效）；想所有文件夹都能用，放 `~/.claude/skills/` |
| 开工说明（`04_模板/开工说明.md`） | 复制到工作文件夹根目录，改名为 `CLAUDE.md` |
| 宪法、记忆卡模板 | 工作文件夹根目录：`宪法.md`、`记忆卡.md` |

实测结果（第 1、2 步）：
- 装好技能后，AI 能识别出 4 个技能；
- 说“按 任务/xxx.md 干活”后，AI 自己按 `split-and-do` 拆步骤，交付文件夹里留下了产出、`graph.md`、`checks.md`、`progress.md`、`说明.md`，一件小活一两分钟做完；
- 新开对话用 `maker-checker` 检查，给出逐条结论和问题单，没有改文件；
- 让 AI 写记忆卡后，再开一个全新对话问“任务单放哪、哪些事要先问、上次的教训”，全部答对。

第一次用：
- 按 Claude Code 官方安装说明安装；需要付费账号（会员或按量付费，价格以官网为准）。
- 在工作文件夹里打开终端（macOS：在访达里右键文件夹 → “新建位于文件夹位置的终端窗口”），运行 `claude`，按提示登录。
- 它第一次要写文件时会停下来问你，选“这次都允许”，之后才能放手让它干。
- macOS 的访达默认不显示 `.claude` 这种点开头的文件夹，按 Cmd+Shift+. 可以显示；也可以直接让 AI 自己建好 `.claude/skills/` 并把技能复制进去。
- 国内网络可能连不上这个工具。连不上就先走聊天版，或看下面“国内用户”两节。

### 聊天版（任何聊天 AI）的做法

做法本身实测过，方式是：把 Claude Code 的所有工具关掉（只能对话、不能读写文件、不能跑程序）来模拟聊天 AI，按第 1 步「聊天版」把宪法、技能、任务单贴进去，能按技能做完并自查；另开对话检查也能出问题单。
**网页或手机上的各家聊天产品没有逐个测过**，见下面“未测”。

## 二、未测的组合（写了做法，没跑过）

### 国内用户：国内聊天 AI 走聊天版（未测）

网页或手机上的国内聊天 AI（比如 DeepSeek、Kimi、豆包、通义），按第 1 步「聊天版」照做：

1. 新开对话，依次粘贴：填好的 `宪法.md`、`03_技能/split-and-do/SKILL.md` 全文、任务单和材料；
2. 粘贴第 1 步「聊天版」第 2 条里那段话；
3. 新开对话，粘贴 `03_技能/maker-checker/SKILL.md` 全文 + 任务单和材料 + 结果，按第 1 步「聊天版」第 4 条的说法让它检查。

要注意：材料太长可能超过单次能贴的长度，先拿小活试。

### 国内用户：Claude Code 接国内模型（未测）

几家国内模型提供了能让 Claude Code 直接连接的接口（具体哪家支持、怎么填，以对方官方文档为准）。思路是：在对方开放平台申请 API 密钥，按对方文档设置几个环境变量，再按上面“Claude Code”一节放技能和开工说明。**密钥只放在环境变量里，不要写进工作文件夹的任何文件。**

### 其他能动手的 AI 工具（未测）

| 工具 | 开工说明放哪（按官方文档） | 技能怎么放 |
|---|---|---|
| Codex 命令行版 | 工作文件夹根目录 `AGENTS.md` | 未测；最简单的做法是在 `AGENTS.md` 里写“开工先读 技能/ 里的 SKILL.md” |
| Gemini 命令行版 | 工作文件夹根目录 `GEMINI.md` | 同上 |
| 带 AI 的编辑器（Cursor、Trae 等） | 各自的“规则”文件，见官方文档 | 同上 |

通用退路：任何能读文件的 AI 工具，都可以把 `03_技能/` 复制成工作文件夹里的 `技能/`，在开工说明里写一句“开工先读 技能/ 里每个 SKILL.md”。

### Windows（未测）

做法一样，只是复制文件夹用资源管理器即可；隐藏文件夹（以点开头的 `.claude`）要在资源管理器里打开“显示隐藏的项目”才看得到。
